# 🎬 Netlura

![Banner](https://raw.githubusercontent.com/mongedecristo/netlura/main/assets/banner.png)

Projeto inspirado na proposta da Netflix, com catálogo de filmes e séries, design responsivo e carrossel de cards.

## 🚀 Visão Geral

Netlura é uma aplicação front-end criada durante a Imersão Dev Alura - Com IA, com objetivo de reproduzir a experiência visual da plataforma Netflix, incluindo:
- Tela inicial com cards de conteúdo
- Carrossel dinâmico
- Responsividade para dispositivos móveis
- Layout escuro estilo streaming

## 🧩 Tecnologias Utilizadas

- 🌐 HTML5
- 🎨 CSS3
- 🧠 JavaScript (ES6+)
- 📁 Estrutura simples de pastas
- 🧩 Arquivos principais:
  - `index.html`
  - `style.css`
  - `script.js`
  - `catalogo/catalogo.html`
  - `catalogo/js/main.js`

## 📦 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/mongedecristo/netlura.git
   ```
2. Abra o arquivo `index.html` no navegador.

## 🌍 Publicação

O projeto está publicado no GitHub Pages:
- https://mongedecristo.github.io/netlura/

## 💡 Inspiração

Netlura foi criado com base na ideia de parecer e lembrar o estilo de navegação e UX da Netflix, com foco em:
- carrosséis de recomendações
- visual limpo e moderno
- organização por categorias
